# 查找与全盘索引

## 快速查找

- 顶部快速查找按文件名或文件夹名片段即时检索。
- 类型下拉可缩小结果范围，清空搜索框会回到时间线。
- 命中结果可区分已入库、等待缩略图、尚未纳入图库和受硬排除规则限制的文件。
- 尚未入库的文件可先用系统关联程序打开，或把所在目录加入图库。

## 全盘快查服务

- Windows 的 NTFS 卷可通过本地索引服务读取 USN/MFT 日志，加速全盘文件发现与保鲜。
- 启用服务需要一次管理员授权；安装后会开机自启。
- 选择「不用全盘快查」可跳过授权；若原先已安装服务，跳过时会一并移除。
- 服务不可用时，发现与保鲜会退回逐目录扫描，但已有图库浏览不受影响。

## 授权与撤销

- 首启授权窗可选择启用、跳过，或关闭后稍后再决定。
- 勾选「不再提示」并拒绝后，开机不再自动询问；入口仍保留在搜索页和选项页。
- 在「选项 > 全盘快查」可重新启用、停止或卸载服务。
- 卸载会停止服务并删除注册项，需要一次管理员授权；本地索引文件仍保留在数据目录。

## 适用范围

- 全盘快查仅支持 Windows 的 NTFS 卷。
- 其他卷会显示原因并采用兼容扫描，不提供实时快查。
