# 浏览与排序

## 视图

- 时间线按拍摄日期分组，适合按月份浏览照片。
- 相簿把一组照片放在一起，可添加描述并长期保留。
- 文件夹视图支持树形和缩略图网格；详细列表可点文件名、创建日期或大小列头排序。
- 工具栏的前进、后退按钮与 `Alt+←`、`Alt+→` 使用同一套视图历史。

## 排序与类型筛选

- 排序菜单可选择日期、名称、大小或类型，并可切换反向排序。
- 类型筛选提供全部、图片、视频等档位；带类型标签时只显示对应媒体。
- 缺少扩展名的照片会按缺省类型处理，不会干扰其他类型的正常排序。
- 排序与筛选状态会保存，重启后继续沿用。

## 标签色筛选

- 标签可设置颜色，筛选条右侧的色板用于按颜色筛选照片。
- 同时选择多种颜色时，命中任一颜色即显示。
- 标签色集合独立保存，不会改变星标、人物、视频等过滤开关的组合。

## 选择照片

- 单击选中单张，`Ctrl+点击` 可追加或取消选择。
- `Ctrl+A` 选中当前视图的全部照片。
- 右键菜单可对选中的一张或多张照片执行操作。
