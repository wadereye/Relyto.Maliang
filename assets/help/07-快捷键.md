# 快捷键

## 选择与浏览

- `Ctrl+A`：全选当前视图的照片。
- `Ctrl+点击`：选中或取消选中单张照片。
- `F1–F8`：快捷标签（可在选项中设置）。
- `PageUp / PageDown`：图库上一页或下一页。
- `Home / End`：跳到图库开头或末尾。
- `Alt+← / Alt+→`：后退或前进到上一个视图。
- `右键`：打开照片上下文菜单。

## 预览

- `← / →`：预览上一张或下一张。
- `Ctrl+R`：预览中顺时针旋转 90 度。
- `Ctrl+Shift+R`：预览中逆时针旋转 90 度。
- `Space`：幻灯片暂停或继续。
- `Esc`：取消扫描；没有扫描时关闭预览。

## 编辑与保存

- `F2`：未配置快捷标签时，保存并烘焙当前预览照片。
- `Ctrl+Z`：编辑视图撤销。
- `Ctrl+Y`：编辑视图重做。

## 说明

- 快捷键只在对应的图库、预览或编辑上下文中生效。
- 需要查看完整清单时，可打开「帮助 > 键盘快捷键…」。
